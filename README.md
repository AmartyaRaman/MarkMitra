# 🧠 MarkMitra — Academic Intelligence Platform

> An AI-powered Academic Intelligence & Automated Evaluation Platform (incubated at MAIT, Rohini), built with the **PERN stack** (PostgreSQL, Express, React, Node.js), **Vite + Tailwind CSS**, and **Docker multi-stage builds**.

---

## 📸 Features

| Module | Description |
|---|---|
| 🔐 **Role-Based Auth** | JWT login for Admin / Teacher / Student |
| 📋 **Assessment Manager** | Create, track, and manage academic evaluations |
| 🤖 **AI Grader** | Upload answer sheets → auto-graded by Gemini 1.5 Flash |
| 📚 **Teacher's Toolkit** | AI-generated lesson plans, question papers, rubrics, worksheets |
| 📊 **Student Analytics** | Bar/Radar charts, at-risk alerts, performance tables |
| 🏛️ **Admin Panel** | Manage users, roles, and institutional settings |

## 🚀 Quick Start

### Option A — Docker Compose (Recommended)

```bash
# 1. Clone and navigate
cd minor-project

# 2. Add your Gemini API key (optional, demo mode works without it)
echo "GEMINI_API_KEY=your_key_here" >> backend/.env

# 3. Start all services
docker compose up --build

# App: http://localhost:80
# API: http://localhost:5000/api/health
```

### Option B — Local Development

```bash
# Terminal 1: PostgreSQL (or use local install)
docker run -d -p 5432:5432 -e POSTGRES_PASSWORD=postgres123 -e POSTGRES_DB=markmitra postgres:16-alpine

# Terminal 2: Backend
cd backend
cp .env.example .env        # Edit DB_HOST=localhost and add GEMINI_API_KEY
npm install
npm run dev                  # http://localhost:5000

# Terminal 3: Frontend
cd frontend
npm install
npm run dev                  # http://localhost:3000
```

### Option C — Production Server

Uses [docker-compose.prod.yml](docker-compose.prod.yml): only port 80 is exposed (Postgres and the API stay inside the Docker network), and the backend refuses to start with weak secrets.

```bash
git clone <repo-url> markmitra && cd markmitra
cp backend/.env.example backend/.env
# Edit backend/.env:
#   DB_PASSWORD      -> openssl rand -base64 24
#   JWT_SECRET       -> openssl rand -hex 32
#   ALLOWED_ORIGINS  -> http://your-domain.com
#   GEMINI_API_KEY   -> your key (optional)

docker compose -f docker-compose.prod.yml --env-file backend/.env up -d --build
docker compose -f docker-compose.prod.yml logs -f backend   # check it booted
```

To update after pulling new code, re-run the same `up -d --build` command.

### Option D — Render

[render.yaml](render.yaml) is a Render Blueprint that creates Postgres, the backend (Docker) and the frontend (static site), all in the Singapore region.

1. Push the repo to GitHub/GitLab.
2. Render dashboard → **New → Blueprint** → select the repo.
3. When prompted, set:
   - `ALLOWED_ORIGINS` → the frontend URL, e.g. `https://markmitra.onrender.com`
   - `GEMINI_API_KEY` → your key, or `your_gemini_api_key_here` for demo mode
4. After the first deploy, check the backend's actual URL. If it isn't `https://markmitra-backend.onrender.com`, update the `/api/*` rewrite destination in `render.yaml` and push.

`JWT_SECRET` and the DB credentials are generated by Render. Pushes to the default branch redeploy automatically. On the free plan, the backend sleeps after inactivity (first request takes ~1 min) and uploaded files are lost on redeploy.

```
    │   Port: 5432       │ │  Port: 5000    │ │  Port: 80       │
    │   Volume: pg_data  │ │  2-stage build │ │  2-stage build  │
    │   Healthcheck ✅   │ │  Non-root user │ │  Gzip + Cache   │
    └───────────────────┘ └────────────────┘ └────────────────-┘
              │                    │                    │
              └────────────────────┴────────────────────┘
                                markmitra-net (bridge)
```

### Multi-Stage Build Strategy
- **Frontend**: Stage 1 (Node 20 Alpine) → `npm run build` → Stage 2 (Nginx Alpine) serves `/dist`
- **Backend**: Stage 1 (Node 20 Alpine) → `npm ci --only=production` → Stage 2 (Node 20 Alpine) runs as `markmitra` non-root user

## 🤖 Gemini AI Integration

Set your API key in `backend/.env`:
```
GEMINI_API_KEY=your_key_from_aistudio.google.com
```

Features powered by Gemini 1.5 Flash:
- **AI Grader**: Vision API analyzes uploaded answer sheet images
- **Lesson Plans**: Curriculum-aligned, NEP 2020 ready
- **Question Papers**: Balanced MCQ + descriptive format  
- **Rubrics & Worksheets**: Structured markdown output

Without a key, the platform runs in **demo mode** with realistic mock responses.
